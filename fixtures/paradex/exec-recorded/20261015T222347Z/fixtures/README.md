# Paradex order-entry frames recorded on testnet

Recorded 2026-10-15 from Paradex testnet (ETH-USD-PERP) by the owner-run acceptance program `paradex_testnet_acceptance` (crates/fbc-examples, FBC-xji8) for FBC-8xr: the frames and REST answers the venue sent during one run of place, amend, cancel, batch create, cancel-many, an IOC expiry and two cancel-on-disconnect cases, in the order received.

Method: the order-entry session's journal (decision 0006), which holds every credential only as a keyed hash, read back and scrubbed: only what the venue sent is kept (never a frame we wrote, which carries order signatures); each SBE order, fill and position frame's 32 account bytes are replaced by the synthetic bytes a0..bf; an account (balance) frame is left out; every `account` value and every 0x string of 40 or more hex digits in JSON is replaced by `SCRUBBED`; a login answer is left out. `.sbe.txt` files are written as the hand-built fixtures in fixtures/paradex/exec/ are (hex bytes, `#` comments); `rest-*.json` are the acceptance program's own GET /orders, /positions and /orders-history reads, scrubbed alike. Every file passed the privacy check's patterns before it was written, an SBE frame's bytes scanned as text before they were written as hex.
