# fueledbychai-rs

Venue-agnostic trading connectivity for Rust: market data and order entry behind common traits,
with one crate per venue. The Rust counterpart of
[FueledByChaiTrading](https://github.com/FueledByChai/FueledByChaiTrading).

First venues: Paradex, then Hibachi (instrument discovery, market data, trading status and the offline order signer so far); Binance USD-M futures for reference market data. QFEX public market data is in progress.

Releases: [CHANGELOG.md](CHANGELOG.md) lists what each tag from v0.0.7 on shipped, by crate,
ticket and pull request, and the API changes a consumer meets when it moves its pin (v0.0.7:
"Pin bump from v0.0.6"); earlier tags have no entry.

To watch live market data (public channels only, no credentials):

```
cargo run -p fbc-examples --example md_watch -- --paradex BTC-USD-PERP --binance BTCUSDT
cargo run -p fbc-examples --example md_watch -- --hibachi ETH/USDT-P --binance ETHUSDT
cargo run -p fbc-examples --example md_watch -- --help
```

To place and cancel one post-only order on Paradex TESTNET (credentials from
`PARADEX_ACCOUNT_ADDRESS` and `PARADEX_PRIVATE_KEY`; the market's tick, size step and minimum
notional from `GET https://api.testnet.paradex.trade/v1/markets`):

```
cargo run -p fbc-examples --example testnet_trade -- --help
```

To run the continuous fixed-offset quoting loop on Paradex TESTNET, a PLUMBING TEST, NOT A
STRATEGY (one post-only order a side a fixed number of basis points behind the touch, requoted
by cancel-and-replace through `fbc-oms`'s planner until Ctrl-C, `--duration` or `--cycles`,
then Stop and a summary; same credentials and market flags):

```
cargo run -p fbc-examples --example testnet_quote -- --help
```
